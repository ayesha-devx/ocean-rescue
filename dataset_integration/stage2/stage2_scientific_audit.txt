2. DETAILED VERIFICATION CHECKS (TASKS 1 – 8)
--------------------------------------------------------------------------------

[CHECK 1] VMDR Sine/Cosine Vector Interpolation
  - Objective  : Verify whether VMDR is interpolated using sine/cosine components
                 during BOTH spatial and temporal interpolation.
  - Code Evidence (`align_environmental_datasets.py`, Lines 69-72):
      vmdr_rad = np.radians(ds_w['VMDR'])
      sin_dir = np.sin(vmdr_rad).interp(latitude=target_lat, longitude=target_lon, method="linear").interp(time=target_time, method="linear")
      cos_dir = np.cos(vmdr_rad).interp(latitude=target_lat, longitude=target_lon, method="linear").interp(time=target_time, method="linear")
      vmdr_out = (np.degrees(np.arctan2(sin_dir, cos_dir))) % 360.0
  - Finding    : Sine and Cosine components are interpolated spatially FIRST, and
                 temporally SECOND, before reconversion via arctan2(sin, cos) mod 360.
                 This prevents 0°/360° boundary wrapping errors.
  - Verdict    : PASS

[CHECK 2] Interpolation Across Land or Unsupported NaN Gaps
  - Objective  : Verify whether interpolation creates values across land or NaN gaps.
  - Finding    : Bilinear spatial interpolation preserves NaN masks from original
                 source ocean datasets (`uo`, `vo`, `VHM0`, `VTM10`, `VMDR`).
                 ERA5 wind (`u10`, `v10`) is a continuous reanalysis model over sea/land.
                 Coastline grid cells maintain clean NaN separation for ocean variables.
  - Verdict    : PASS WITH WARNINGS (Standard bilinear spatial weighting at coastline;
                 `land_mask` should be applied downstream).

[CHECK 3] Land Mask Derivation & GEBCO Missing Elevation Cells
  - Objective  : Check whether land mask is derived consistently from bathymetry and
                 whether missing elevation cells are distinguished from land.
  - Finding    :
      * True ocean cells (`elevation < 0`): 4,502 cells -> assigned `land_mask = 1`.
      * True land cells (`elevation >= 0`): 539 cells -> assigned `land_mask = 0`.
      * Outer boundary edge cells: 288 cells at exact perimeter (`lat=14.0`, `lat=20.0`,
        `lon=68.0`, `lon=74.0`) lie 0.002083° (~225 m) outside GEBCO pixel centers
        (`14.00208°` to `19.99792°`), producing 288 edge NaNs during linear interpolation.
      * In `land_mask = xr.where(b_spatial < 0, 1, 0)`, edge NaNs evaluate to `0` (land).
  - Verdict    : WARNING (Boundary edge cells are classified as land/NaN due to GEBCO pixel-center
                 bounding box; easily resolved by boundary extrapolation if needed).

[CHECK 4] Bathymetric Physical Consistency (`water_depth`)
  - Objective  : Verify whether `water_depth` is physically consistent with original
                 GEBCO elevation and its positive-up convention.
  - Code Evidence (`align_environmental_datasets.py`, Line 92):
      water_depth = xr.where(b_spatial < 0, -b_spatial, np.nan)
  - Finding    : Original GEBCO elevation is negative underwater (-4,108.5 m) and positive
                 on land (+1,368.5 m). Derived `water_depth` is strictly positive-down
                 (0.00 m to 4,108.50 m) over ocean cells, and NaN over land cells.
  - Verdict    : PASS
