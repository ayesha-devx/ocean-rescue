  - Total Mesh     : 73 x 73 = 5,329 grid points per timestamp.

Spatial Regridding Methods:
  - Ocean Currents (`uo`, `vo`) : Bilinear spatial interpolation from 73x72 ocean grid to 73x73 target mesh.
  - ERA5 Wind (`u10`, `v10`)    : Bilinear spatial interpolation from 25x25 (0.25°) grid to 73x73 target mesh.
                                  Latitude array sorted ascending (14° to 20°N) prior to interpolation.
  - Waves (`VHM0`, `VTM10`)     : Bilinear spatial interpolation from 73x73 wave grid.
  - Wave Direction (`VMDR`)     : Decomposed into sin(VMDR) and cos(VMDR) vectors prior to spatial/temporal
                                  interpolation to prevent 0°/360° boundary wrapping errors, then reconstructed
                                  via arctan2(sin, cos) mod 360°.
  - Bathymetry (`elevation`)    : Bilinear spatial interpolation from GEBCO 15 arc-second (~450m) 1440x1440 grid.
  - Water Depth (`water_depth`) : Derived as `-elevation` where `elevation < 0` (positive-down in meters).
                                  Land points (`elevation >= 0`) are set to NaN.
  - Land-Ocean Mask (`land_mask`): Binary mask (1 = ocean, 4,502 cells; 0 = land, 827 cells).
