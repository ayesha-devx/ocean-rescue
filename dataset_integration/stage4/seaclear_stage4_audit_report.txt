10. ISSUES AND LIMITATIONS
--------------------------------------------------------------------------------

  ISSUE 1 -- No "info" or "licenses" block in dataset.json
    COCO standard includes these keys; SeaClear's JSON omits them.
    No version, date, or license metadata is embedded in the file.

  ISSUE 2 -- Bare filename format (no site/camera prefix)
    Loading code must perform a disk-walk basename resolver.
    Zero filename collisions detected across 8,610 files.

  ISSUE 3 -- No train/val split defined
    A single dataset.json covers all 8,610 images with no split.
    Any ML training workflow must define its own split strategy.

  ISSUE 4 -- Class imbalance
    animal_urchin (6,462) is 6.7x more frequent than net_plastic (960).
    rope_plastic has only 8 annotations -- severely underrepresented.

  ISSUE 5 -- ROV equipment categories must be excluded from debris detection
    4 categories represent the collection ROV itself (rov_cable, rov_tortuga,
    rov_vehicle_leg, rov_bluerov). These must be filtered for debris detection.

  ISSUE 6 -- cable_metal class ambiguity
    May represent mooring cables, anchor chains, or ROV cables.
    No further disambiguation available in the annotation metadata.

  VALIDATION VERDICT: PASS
    All annotations structurally valid. Zero missing images.
    Zero degenerate bounding boxes. Zero empty segmentations.
