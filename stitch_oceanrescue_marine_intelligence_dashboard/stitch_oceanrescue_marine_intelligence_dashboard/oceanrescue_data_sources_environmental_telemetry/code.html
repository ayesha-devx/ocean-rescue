Data Provenance, Projections & Responsible Academic Use

Spatial Reference Standards All geospatial vectors and bounding polygons are transformed from EPSG:4326 (WGS84 datum) into EPSG:3857 (Web Mercator) for client screen rasterization. Benthic soundings reference mean sea level (MSL) per GEBCO 2024 specifications.
Open Data Licensing Atmospheric and oceanic forcing vectors are incorporated under Copernicus Open Access and NOAA Public Domain terms. GEBCO bathymetric grids are attributed under IHO-IOC Consortium guidelines.
Capstone Disclaimer This application represents a Computer Engineering capstone validation prototype. Telemetry and hydrographic vectors presented herein are simulated for demonstration purposes and must not be utilized for official SOLAS vessel navigation.
